PhotoCull 0.1.0 - third-party software notices
================================================

PhotoCull is a local, offline photo-culling tool. This package contains the third-party components below.
Licence texts are in the LICENSES folder next to this file. This file is an inventory and notice, NOT legal
advice and NOT a statement that every licence obligation has been met: see "Open points" at the end.

7. Microsoft Visual C++ runtime (VCRUNTIME140*, MSVCP140*)
   Not bundled. PhotoCull needs Microsoft's current Visual C++ Redistributable (x64) installed:
   https://aka.ms/vc14/vc_redist.x64.exe . The build removes every vcruntime140*/msvcp140* file, including NumPy's
   renamed numpy.libs\msvcp140-<hash>.dll, and fails if one reappears (packaging\photocull.spec, packaging\build.ps1).
   The Universal C Runtime is part of Windows 10 and later.
   NumPy's two C++ extension modules (numpy\_core\_multiarray_umath*.pyd, numpy\fft\_pocketfft_umath*.pyd) import
   that renamed file by its exact name. The build (packaging\unmangle_msvcp.py) overwrites that one import-table
   name string in each of the two files with "msvcp140.dll" (padded with NUL, same length; nothing else changes),
   so they load the redistributable the user installed. LICENSES\NumPy-import-patch.txt records the exact
   offsets and SHA-256 of both files before and after. NumPy is modified only in this way; its licence
   (LICENSES\NumPy-LICENSE.txt) is unchanged. Nothing from Microsoft is in this ZIP, no Microsoft file is copied at
   run time and nothing is written outside the user's PhotoCull data folder. If the redistributable is missing
   altogether, Windows reports "Failed to load Python DLL" before PhotoCull can show its own message.
